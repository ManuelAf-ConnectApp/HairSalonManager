# ADR 0002 — Documentos de composición, sin emisión fiscal

**Estado:** aceptada · **Fecha:** 2026-10-30

Hair Salon Management se distribuirá como proyecto de código abierto orientado a gestionar y componer **borradores**. Su salida PDF es una previsualización de composición, marcada de forma visible como documento de prueba y sin valor de factura emitida.

El proyecto no implementa ni habilita emisión de facturas reales, series o numeración fiscal, registros de facturación, cobros vinculados a facturas emitidas, QR tributario, huellas, encadenamiento, firma ni remisión a la AEAT. Tampoco declara conformidad SIF, VERI*FACTU o NO VERI*FACTU.

Quien distribuya, adapte o use una versión para facturar operaciones reales asume la responsabilidad de determinar la normativa aplicable, escoger modalidad y completar, probar y documentar el cumplimiento correspondiente. Esta decisión evita que una composición visual se confunda con un documento fiscal.
